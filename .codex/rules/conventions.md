# General Conventions

Apply across the whole repo.

1. **Dates:** ISO 8601 throughout (`2026-04-30`).
2. **Encoding:** keep files UTF-8 and prefer plain ASCII in source and docs unless the content itself requires otherwise.
3. **Naming:** follow the language-local rules in each app. React component files use `PascalCase.tsx`; Java source files follow standard `PascalCase.java`; non-component frontend files use kebab-case.
