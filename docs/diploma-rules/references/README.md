## Як використовувати

- Це **приклад композиції готової роботи**, а не заміна офіційних правил.
- Для формальних вимог пріоритет завжди має `../RULES.md`.
- При генерації нової роботи орієнтуватися на приклад щодо:
  - загального ритму документа;
  - співвідношення вступу, розділів, висновків і додатків;
  - способу подання рисунків, таблиць, лістингів і списку джерел;
  - того, як виглядає завершена робота як цілісний артефакт.

## Додаткові локальні еталони для project skills

Ці файли додано з `Ilyaberbx/diplomna_robota` для локальних skills презентації,
звіту з практики та щоденника:

- `PRESENTATION-RULES.md` - правила структури й перевірки презентації до захисту.
- `sample-presentation-1.pptx`, `sample-presentation-2.pptx` - еталонні презентації;
  другий файл використовується skills як стильовий шаблон.
- `ZVIT-RULES.md` - правила структури звіту з переддипломної практики.
- `SHODENNYK-RULES.md` - правила структури щоденника практики.
- `Звіт.docx`, `Щоденник.docx` - візуальні еталони офіційних форм.
- `sample-work.pdf`, `sample-work.txt` - приклад роботи з upstream-репозиторію для
  звірки структури, коли skill потребує готового прикладу.
- `upstream-scripts/` - приклади upstream-скриптів збірки презентації, PDF, діаграм,
  скриншотів, звіту та щоденника. Вони збережені як reference-код, а не як готові
  робочі інструменти цього проєкту, бо upstream очікує теку `thesis/`.
