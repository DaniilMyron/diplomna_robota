# Правила оформлення дипломної роботи

Ця папка містить локальну робочу базу за офіційними правилами Національного університету "Одеська політехніка" для оформлення текстової частини кваліфікаційних робіт бакалавра та магістра.

## Що тут є

- `sources/` - локальні копії офіційного PDF та додатків А-Г.
- `extracted/` - текст, витягнутий з офіційних файлів для пошуку й аналізу.
- `RULES.md` - канонічна робоча систематизація правил, якою зручно користуватися під час написання.
- `rules-summary.md` - попередня назва стислого конспекту; залишена як допоміжний дубль.
- `checklist.md` - практичний чекліст перед здачею документа.
- `appendices.md` - що саме дають офіційні зразки А-Г.
- `sources.md` - перелік джерел і статус документів.

## Як користуватися

1. Під час написання розділу звірятися з `RULES.md`.
2. Перед експортом документа проходити `checklist.md`.
3. Для титульного аркуша, анотацій, змісту та вступу брати структуру з офіційних додатків у `sources/`.
4. Для перевірки готового `.docx` використовувати скілл `/grill-with-diplom`.
